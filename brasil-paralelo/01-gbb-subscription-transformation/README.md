# GBB Subscription Model Transformation — Full-Stack Monetisation Program

**Brasil Paralelo · 2022 · 5 months across 3 Shape Up cycles**

---

## Problem

BP had 15+ subscription plans differentiated by content category — no upgrade path, no clear value proposition, just a confusing menu of SKUs that made acquisition harder and operations complex.

---

## Key Results

- **~335,634 subscribers migrated** with zero billing disruptions and zero critical outages
- Plan distribution: Good 251,392 · Better 20,205 · Best 64,037
- 15+ plan SKUs retired; acquisition now operates on a single, coherent tier structure
- Projected lifetime PBT: **R$27,387,500** on a program cost of R$70,000
